🚀 Beginner Tasks(nexus-ui)
1. Responsive Landing Page

Build a modern and fully responsive landing page using React and Framer Motion. The landing page should include a visually appealing Hero Section, a responsive Features Grid, a Testimonials section, and a clean Footer layout. Add smooth scrolling navigation between sections to improve user experience and create a professional single-page website feel.

❖ Features:

Hero Section
Features Grid
Testimonials Section
Responsive Footer
Smooth Scroll Navigation
Modern UI Design
Mobile Responsive Layout
